# ResumeLens-AI
AI-powered Resume Analyzer that evaluates resumes, provides a score, identifies strengths, suggests improvements, and highlights missing or unnecessary content.

🚀 Features

📄 Upload resume in PDF format

🎯 Enter a target job role

📊 Get a resume score out of 100

💪 Identify resume strengths

🔧 Get improvement suggestions

🗑️ Identify unnecessary content

➕ Get suggestions for missing sections

📈 Analyze skills, structure, projects, experience and language

📱 Responsive and modern UI

✨ Animated glassmorphism design

🛠️ Technologies Used

HTML5

CSS3

JavaScript

PDF.js

GitHub Pages

📊 Resume Scoring

The application evaluates resumes using five categories:

Content & Impact

Skills Relevance

Structure & Formatting

Projects & Experience

Language & Clarity

Each category is scored out of 20, for a total score of 100.

▶️ How to Use

Open the ResumeLens AI website.

Enter your target role, for example Data Analyst Intern.

Upload your resume as a PDF.

Click Analyze Resume.

Review your score, strengths and improvement suggestions.
